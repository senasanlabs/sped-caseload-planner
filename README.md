# Sena San — Free Digital Companion

Download page for the free fillable PDF companion to the
*Special Education Teacher IEP & 504 Caseload Planner* (2026–2027 edition).

Published with GitHub Pages from `main` → `/docs`.
The PDF lives in `release/` and is published as a GitHub Release asset (download counts)
by `.github/workflows/release.yml` when a tag like `2026-27` is pushed.
The PDF is regenerated from the planner's production kit (`npm run companion`).
